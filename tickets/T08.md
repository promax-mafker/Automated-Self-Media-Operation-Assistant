# T08 · 发布包、发布记录与数据回流

- 批次：4
- 依赖：T01 已合并；T04（图片）与 T06（文案）已合并
- 能力：把「生成」接到「发布」与「复盘」的那一段人工闭环

## 1. 目标

让一个人从「一堆文件」变成「一个可以直接照着发的包」，并把发出去的结果收回来：

- `wb pack build`：按平台生成发布目录（文案 + 图片/视频 + manifest + 合规声明），打包成 zip。
- `wb pack list` / `wb pack show`：看有哪些包、状态如何。
- `wb pack log`：记录「已发到哪个 URL、什么时间」，状态 `draft → exported → published`。
- `wb pack backfill`：把平台导出的 CSV 回灌成 `post` + `metric`，形成 T02 复盘的数据源。

## 2. 可写路径

```

```

## 3. 非范围

- **不登录任何平台、不自动发布、不调平台 API**。`Publisher` 只做本地打包；对接 `social-auto-upload` 的适配位只留函数签名 + `NotImplementedError(明确消息)` + 文档说明。
- 不做定时发布、不做多账号授权管理。
- 不改 `pack` / `post` / `metric` 表结构。

## 4. 契约要点

- 包目录：
  ```
  <WB_HOME>/packs/<pack_id>/
    文案.md          正文 + 标题 + 话题标签（按平台格式：小红书首行标题 + 标签行；抖音口播稿）
    图片/01.png...
    视频/video.mp4    （若有）
    manifest.json
    发布说明.md       含 AI 生成声明、合规检查结果、建议发布时间、平台注意事项
  ```
- `manifest.json` 必含：`pack_id / platform / copy_set_id / title / body / tags[] / assets[{id,path,width,height,duration_sec}] / ai_generated=true / compliance{passed,hits} / suggested_publish_at / checksums{path: sha256} / created_at`。
- AI 声明：`manifest.ai_generated` 必须为 `true`，`发布说明.md` 里给一段可复制到平台的标识话术（依据 ADR 0002 §5.1）。
- `pack log --pack <id> --url <url> [--at <iso>]`：写 `pack.status='published'` 并把 url 写进 manifest；同一 pack 重复 log 以最后一条为准。
- `pack backfill --csv <平台导出.csv> [--account <handle>]`：按 `url` 匹配已有 `post`，命中则新增一条 `metric`（`captured_at` 取 CSV 的抓取时间列，缺省用今天）；
  未命中则新建 `account` + `post` + `metric`。**幂等**：同 `(post_id, captured_at)` 不重复插入。
- `wb pack build --copy <copy_set_id> --assets <id,id> --platform xhs --out <dir>`；`--assets` 可省略（自动取该 copy 关联的 asset）。

## 5. 验收标准

1. 造一条 copy + 2 张图：`wb pack build --copy <id> --platform xhs` → 目录结构齐全，`manifest.json` 可 `json.load`，`checksums` 覆盖全部文件且校验一致。
2. `发布说明.md` 含：AI 声明话术、`compliance.passed` 的实际值、建议发布时间（由 T02 指标算的行/时段，若无数据则给默认并注明「无数据，按默认」）。
3. `wb pack log --pack <id> --url https://example.com/p/1` → `status=published`；再 log 一次不同的 url → manifest 里只有一个最新 url，`pack` 表仍 1 行。
4. `wb pack backfill --csv tests/fixtures/export_sample.csv` → 输出 `matched=2 created=1 metrics=3`；再跑一次 → `matched=3 created=0 metrics=0`（幂等）。
5. `Publisher` 的自动发布入口调用即抛 `NotImplementedError`，消息里明确写「本项目不自动发布，请人工发布后用 wb pack log 记录」。
6. `pytest -q` 覆盖：checksum 校验、幂等 log、backfill 三条匹配分支（命中/未命中/重复）、manifest 必填字段齐全。
