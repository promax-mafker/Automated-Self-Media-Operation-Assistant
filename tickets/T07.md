# T07 · 60 秒短视频合成（卡片分镜 → MP4）

- 批次：3
- 依赖：T01 已合并（`contracts.VideoComposer`、`asset` 表、CLI 自动挂载）
- 能力：视频自动化生成（卡片式分镜，非数字人、非自动剪辑）

## 1. 目标

给一份分镜 JSON，直接产出一条**能发的竖版 MP4**：

- 9:16 / 1080×1920 / H.264 / 25fps，时长 ≤ 60 秒（超出自动截断并 warning）。
- 分镜三种卡片：`title`（大标题卡）、`points`（要点卡，逐条出现）、`cta`（结尾引导卡）。
- 可选配音：`edge-tts`（需要网络）；无网络或关闭时，自动降级为静音 + 字幕条，**不报错**。
- 产物写 `asset` 行（`kind='video'`），带时长、尺寸、字节数。

## 2. 可写路径

```
workbench/video/__init__.py        # 必须提供 build() -> VideoComposer
workbench/video/storyboard.py      # 解析与校验分镜 JSON
workbench/video/frame.py           # Pillow 画卡片
workbench/video/compose.py         # ffmpeg 组装
workbench/video/tts.py             # edge-tts 可选配音
workbench/stages/video.py          # stage: video_build
workbench/cli_ext/video.py         # wb video ...
templates/video/default.json       # 分镜模板（3 种卡片的时长与版式）
docs/video.md
tests/test_video.py
```

## 3. 非范围

- 不依赖 T04 的渲染代码（自绘卡片，避免跨 Ticket 耦合）；不引入 MoviePy。
- 不做转场特效库、不做 BGM、不做素材库、不做数字人。
- 不改 `asset` 表结构；meta 里放 `{scenes, fps, tts}`。
- 不装系统 ffmpeg：只用 `imageio_ffmpeg.get_ffmpeg_exe()` 返回的二进制。

## 4. 契约要点

- 分镜 JSON：`{"title","scenes":[{"type":"title|points|cta","text","points?":[...],"seconds":N}],"tts":false}`
  校验：`seconds` 合计 ≤ 60（超出按比例缩放并 warning），每个 `points` ≤ 5 条，空 text 报 `ValidationError`。
- 帧生成：每秒取 1 帧太糙，按 25fps 生成图片序列代价高；用「每张卡片渲染 1 张 PNG + ffmpeg `-loop 1 -t <seconds>`」拼，
  `points` 卡的逐条出现用 2-3 张 PNG 切成多段实现。
- 组装：`ffmpeg -f concat -safe 0 -i list.txt -vf "scale=1080:1920,format=yuv420p" -r 25 -c:v libx264 -crf 23 -preset veryfast out.mp4`。
- 配音（可选）：`edge-tts --voice zh-CN-XiaoxiaoNeural --text ... --write-media a.mp3`；失败即降级静音（`ctx.log` warning），
  且 `tts=true` 时音频长度不得改变视频时长（视频时长以分镜为准）。
- CLI：`wb video build --storyboard s.json --out v.mp4 [--tts]`；`wb video template` 打印内置模板。
- 产物入库：`asset(kind='video', duration_sec=实际时长, width=1080, height=1920, bytes=文件大小)`。

## 5. 验收标准

1. `wb video template > /tmp/sb.json` 能拿到可用的分镜模板（≥3 个场景）。
2. `wb video build --storyboard /tmp/sb.json --out /tmp/v.mp4` 成功，产出文件 > 50KB。
3. 用 `imageio_ffmpeg` 的 ffmpeg `-i` 解析输出，断言：`1080x1920`、`h264`、`25 fps`、时长在 `[期望 ±0.5s]`。
4. 超长分镜（合计 90 秒）→ 自动压到 60 秒，warning 文案含原始与压缩后时长，视频实际时长 ≤ 60.5s。
5. `--tts` 在无网络环境下（测试内 monkeypatch `subprocess.run` 抛 `FileNotFoundError` 或网络异常）→ 仍然产出静音视频，退出码 0，日志有 warning。
6. `asset` 表新增 1 行，`duration_sec` 与 ffmpeg 解析值差 < 0.2s。
7. `pytest -q` 覆盖：分镜校验三条失败路径、时长截断、静音降级、ffmpeg 命令拼装（用假二进制断言 args，不真跑）。
