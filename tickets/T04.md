# T04 · 图文与海报渲染（Pillow + 声明式模板）

- 批次：2
- 依赖：T01 已合并（`contracts.Renderer`、`asset` 表、CLI 自动挂载）
- 能力：营销海报生成、图文（小红书九图 / 竖版封面）

## 1. 目标

给一份文案数据（JSON）和一套模板 ID，直接产出**能发的 PNG**：

- 5 套海报模板 + 3 套图文模板，尺寸覆盖 3:4（1080×1440）、1:1（1080×1080）、9:16（1080×1920）。
- 排版由模板声明，文字自动换行、超长截断加省略号并 warning，**不允许越界或叠字**。
- 同一份数据 + 同一套模板，两次渲染结果结构一致（尺寸、块位置、文本内容）。

## 2. 可写路径

```
workbench/render/build.py           # 必须提供 build_renderer() -> Renderer（名字见 contracts.py）
workbench/render/layout.py
workbench/render/text.py
workbench/render/fonts.py
workbench/render/blocks.py
workbench/stages/visual.py          # stage: render_assets
workbench/cli_ext/render.py         # wb render ...
templates/tokens.yaml               # 品牌色/字号/间距
templates/poster/*.json             # 5 套
templates/carousel/*.json           # 3 套（含 pages）
docs/render.md
tests/test_render.py
```

## 3. 非范围

- 不引入浏览器 / Playwright / HTML 渲染（ADR §3 已否）。
- 不做图片合成素材（`image` 块只支持纯色占位 + 可选本地文件，缺失时画占位框）。
- 不改 `assets/fonts/`（只读）；字体用 `WB_FONT_DIR`（默认 `assets/fonts`）查找 `NotoSansSC-Regular.otf` / `NotoSansSC-Bold.otf`。
- 不做动图、不做视频（T07）。

## 4. 契约要点

- 模板 JSON 结构：`{"id","label","canvas":{"width","height","background","pad"},"blocks":[...]}`；
  块类型固定 6 种：`text` / `list` / `panel` / `chips`（话题标签）/ `divider` / `image`。
- `text` 块字段：`slot,x,y,size,weight(regular|bold),color,max_width,max_lines,line_height,align`。
  换行按 `max_width` 逐字测宽（中文按字、英文按词），超过 `max_lines` 截断并追加 `…`，同时 `ctx.log` 一条 warning。
- 数据字段约定：渲染输入是 `{"slots": {...}, "meta": {...}}`，缺 slot 时用 `templates/tokens.yaml` 里的 `placeholder`。
- `Renderer.render(spec)` 返回 `RenderResult(path,width,height,bytes)`；图片必须真实可打开（测试用 `PIL.Image.open` 校验）。
- 九图模板：`--out` 传目录，生成 `01.png ... 0N.png` + `manifest.json`（页码顺序、每页文案）。
- 版式约束：块坐标 = 相对画布左上角（含 pad 偏移），渲染前做一次「所有块 bbox ⊂ 画布 - 安全边距」检查，越界直接抛 `LayoutError`（这是模板作者的错，不是数据的错）。

## 5. 验收标准

1. `wb render list` 列出 5 套 poster + 3 套 carousel 的 `id / 尺寸 / 页数`。
2. 对每套模板跑一遍：`wb render poster --template <id> --data tests/fixtures/poster_data.json --out /tmp/r/<id>.png`，
   8 个文件全部产出，`PIL.Image.open` 成功，宽高与模板声明一致。
3. 九图：`wb render carousel --template xhs-nine --data tests/fixtures/carousel_data.json --out /tmp/r/nine` 产出 `01.png..09.png` + `manifest.json`。
4. 超长文案：给 `title` 塞 200 字，渲染成功且输出含 `…`，日志有 warning（用 `caplog` 断言）。
5. 越界模板：故意把某块 `x` 设为画布宽 + 100，渲染抛 `LayoutError`，测试断言异常类型与消息。
6. 字体缺失：`WB_FONT_DIR=/tmp/empty wb render ...` 抛 `Unavailable` 且提示「把 CJK 字体放到 assets/fonts/」。
7. `pytest -q` 覆盖：块类型各一个单测、截断分支、越界分支、字体缺失分支、九图页数。
